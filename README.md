Project Overview

This project combines an interactive quiz application with a live weather checker.

Features

- Interactive quiz with multiple-choice questions.
- Automatic answer checking.
- Score tracking.
- Final quiz score.
- Weather information by city name.
- Error handling for invalid city names.
- Responsive user interface.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API

Project Files

- "index.html" – Application structure.
- "style.css" – Application design.
- "script.js" – Quiz and weather functionality.

How to Use

1. Open the application.
2. Answer the quiz questions.
3. Check your score.
4. Enter a city name in the weather checker.
5. Click Get Weather to view weather details.
